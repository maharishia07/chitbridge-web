# K2 critique — e2e/till-scale.cjs flaked once in cloud walks (TEST-LOG W2-1)

**Cause (by reading, not running).** The harness waits only for `typeof window.setMode === 'function'`, which is true as soon as the
script parses. The page's own boot `load()` (till.html, called un-awaited near the end of the file) is still mid-flight: it awaits
`pickHost()` and `HOST.state()`, then sets `S`, re-reads WHO, repaints, and can `refresh()`. The harness seeds `HOST/WHO/S` in that gap,
so a slow runner lets boot land after the seed and replace `S` (Tomato not found → cart empty) or overwrite `#lastnote` (message
checks). Fast runners always won the race, hence "passed on re-run".
The fixed `setTimeout(400)` / `waitForTimeout(n)` sleeps were also dead weight: `searchTyped()` → `scanned()` is synchronous.

**Product:** no race in till.html itself — boot is correct for a real counter, which seeds nothing. Harness-only fix; no twin PR.

**Fix.** Wait for boot to finish (HOST chosen, `#tillpill` painted by load(), network idle) before seeding; drop the sleeps on
synchronous calls; replace the settings-panel sleeps with waits on the control's own effect (`#set_weighex` text, `#row_weighmask`
visibility). No fixed sleeps remain in the file.
