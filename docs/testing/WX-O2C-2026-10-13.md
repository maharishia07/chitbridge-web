**Stack:** `postgres:16` (docker) · api `tools/sim-load.cjs --schema --country IN --shop simstores` — first on the default years (2026-04 → 2029-03),
then on `--start 2023-04-01` (cb_sim2, the years end before today; added this round, see F10). `--country AU` is **refused in words** (no AU

`e2e/lib/walk.cjs`. Two parties: the storefront shopper (a fresh one per run) and the shop; Ravi Stores (the loader's credit customer) for the bill.

then `--only S5,S6,S7,S8` (S8 must run with S5: a return is taken on the counter that rang the bill), then `--only S9,S10`. No flag = fixture
